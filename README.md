# Kollegiale Fallberatung

`fallberatung/index.html` führt durch die acht Phasen der kollegialen Fallberatung (angelehnt an Bennewitz & Grabosch 2017 und Luca & Iwers 2006). Pro Phase zeigt das Tool die Rollen, die Leitfragen und einen Timer. Alle Felder lassen sich per Mikrofon füllen. Am Ende entsteht ein Protokoll als PDF.

Die Datei im Browser öffnen, fertig. Sie braucht keine Installation und kein Internet.

- Spracheingabe: Chrome, Edge oder Safari. Firefox kann es nicht, dort hilft die Diktierfunktion des Betriebssystems.
- Sprachbefehle beim Diktieren: „Komma“, „Fragezeichen“, „Doppelpunkt“, „neue Zeile“, „neuer Absatz“. Jede Sprechpause beendet einen Satz mit Punkt.
- Datenschutz: Chrome und Edge schicken die Audiodaten zur Erkennung an Google bzw. Microsoft. Deshalb keine Klarnamen nennen. Die Texte selbst bleiben nur im Browser gespeichert.
